bot1

Este proyecto consiste en un bot de IA para Discord alojado en Google Colab que analiza automáticamente las imágenes compartidas en un chat y responde indicando qué es la imagen, junto con la probabilidad de la predicción. Al conectar la API de Discord con un modelo de aprendizaje profundo (*Deep Learning*) entrenado que se ejecuta en la infraestructura en la nube de Colab, el bot ofrece una identificación visual automatizada e instantánea directamente en tu servidor.
